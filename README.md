# kokiai.net

Source code of [kokiai.net](https://kokiai.net), the personal website of Koki Xu (邓小闲) — lawyer turned AI builder, founder of the Anti-Distill community at KOKIAI.

Plain static HTML/CSS/JS. No build step. Deployed on Cloudflare Pages.

## What's inside

- `index.html` / `zh.html` — homepage (EN / 中文）: Anti-Distill, insights, public calendar and coffee chat sections
- `works/` — portfolio: Anti-Distill Skill, media coverage, Social Coding, open-source projects
- `services/` — KOKIAI services and the Silicon Valley Legal Tech Frontier community
- `bay-area/` — Bay Area hub page
- `bay-area-map/` — Jensen Huang's Silicon Valley Map: 135 places tied to 24 tech figures (homes, favorite restaurants, cafés and everyday spots), in English, 简体中文 and 日本語
- `sf-2026/` — public calendar, auto-synced daily from a private calendar; only events marked public appear
- `resources/` — AI Library: model pricing, inference providers, community and career playbooks (EN / 中文）

## Notes

- The Anti-Distill star count on the homepage is fetched live from the GitHub API in the visitor's browser.
- Map data (places, stories, sources) is embedded in the map HTML files as JSON.
