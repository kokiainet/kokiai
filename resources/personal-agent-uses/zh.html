用法 1

找房不用自己刷

我自己的案例。我把要求给了 Muse 和 Grok Bot，它们在加州的租房网站上帮我筛符合条件的房源。能直接回复帖子的，它们就回复；不能的，就把联系方式带回来，连消息都帮我写好了，我点发送就行。

出处：我自己的案例
用法 2

水管公司的运营全交给它

一位水管公司老板用 Muse 更新工单、给客户发短信、发 Slack 更新、提醒技师，让两次上门之间的跟进工作自己跑起来。

健身动作的私人教练

一位用户把自己录的训练视频传上去，让 Muse 对照标准动作分析他的姿势，再问怎么调整。比再来一份通用训练计划有用得多。

追回航司退款

一位用户说他拿回了航司 200 美元退款。Agent 按日程持续跟进、发提醒邮件，甚至能打电话，这种耐心是大多数人没有的。

给孩子找奖学金

一位家长在 Instinct 的评论区说，他用自己的 agent 帮女儿找奖学金。

把个人信息从人员搜索网站上删掉

这类网站把你的家庭住址、电话号码和家人关系卖给任何人。一位用户让 Instinct 准备了 6 个网站的删除申请，最后的确认由他自己点击。

用法 7

替你盯机票价格

一位用户让自己的 agent 按日程查机票价格，票价降到合适的水平就提醒他。
